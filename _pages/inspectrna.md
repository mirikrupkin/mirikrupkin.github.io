**InspectRNA** is an open repository and interactive 3D viewer for isolated viral regulatory RNA structures from the Protein Data Bank, shown side by side with their Boltz-2 predictions.

**[Open the interactive viewer](https://mirikrupkin.github.io/inspectrna/)** · [Data and code on GitHub](https://github.com/mirikrupkin/inspectrna)

## What you can do

* Browse and filter targets by family, length and organism.
* Compare each experimental structure with its prediction, side by side or overlaid.
* Color predictions by pLDDT or by per-residue deviation from the reference.
* Download the cleaned reference and prediction files and the metrics table.

## About the data

The reference structures are cleaned versions of PDB entries (model and chain selection, renumbering), and the predictions are superposed onto them. See the repository README for full provenance and metric definitions.
